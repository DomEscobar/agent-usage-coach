# Agent Usage Coach

This repository is a portable coding-agent skill, not a product codebase.

On every coding turn, read and follow [SKILL.md](SKILL.md). Coach the human's process. Do not treat this file as a second policy.

Load [anti-patterns.md](anti-patterns.md) only when a violation is suspected. Load [good-briefs.md](good-briefs.md) only when rewriting a brief.

User prompts override this file. The closest extra `AGENTS.md` in a consumer repo wins for that repo's own rules; it does not replace this skill.
